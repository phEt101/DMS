# `reset-passwords` — รีเซ็ตรหัสผ่านผู้ใช้ทุกคนเป็นรหัสเดียวกัน

Script สำหรับรีเซ็ตรหัสผ่านของผู้ใช้ทุกบัญชีที่ยัง active ให้เป็นรหัสเดียวกัน ใช้ตอนต้องการให้ทุกคนเข้าสู่ระบบด้วยรหัสชั่วคราว แล้วเข้าไปเปลี่ยนรหัสเองในระบบ

ไฟล์: `server/scripts/reset-passwords.ts`

## การใช้งาน

รันจาก `server/`:

```bash
npx tsx scripts/reset-passwords.ts --password=12345678
```

หรือตั้งผ่านตัวแปรแวดล้อม (ใช้ค่าเดียวกับ seeder):

```bash
SEED_DEFAULT_PASSWORD=12345678 npx tsx scripts/reset-passwords.ts
```

> ปัจจุบันยังไม่มี npm script ห่อไว้ — รันด้วย `npx tsx` ตรง ๆ ตามด้านบน

## ตัวเลือก (Options)

| ตัวเลือก | คำอธิบาย |
| --- | --- |
| `--password=xxxx` | รหัสผ่านใหม่ที่จะตั้งให้ทุกบัญชี (จำเป็น ถ้าไม่ตั้ง `SEED_DEFAULT_PASSWORD`) |
| `--dry-run` | แสดงรายชื่อบัญชีที่จะถูกแก้ โดยยังไม่แก้จริง (แนะนำให้รันก่อนทุกครั้ง) |

## พฤติกรรม

- แก้เฉพาะบัญชีที่ `is_active = 1` — บัญชีที่ปิดใช้งานแล้วไม่ถูกแตะต้อง
- เข้ารหัสด้วย `bcrypt` (cost 12) เหมือนที่ระบบ login ใช้
- ก่อนรันจริงจะแสดงจำนวนบัญชีที่จะถูกแก้ และตอน `--dry-run` จะแสดงรายชื่อ (id, ชื่อ, อีเมล) ทีละคน

## กติกาความปลอดภัย

- ไม่ระบุ `--password` และไม่มี `SEED_DEFAULT_PASSWORD` → ฟ้อง error ทันที
- รหัสสั้นกว่า 8 ตัวอักษร → ฟ้อง error

## ตัวอย่าง

```bash
# ดูก่อนว่าจะแก้บัญชีไหนบ้าง
npx tsx scripts/reset-passwords.ts --password=12345678 --dry-run

# รีเซ็ตจริง
npx tsx scripts/reset-passwords.ts --password=12345678
```

### ตัวอย่างผลลัพธ์

```text
พบผู้ใช้ที่ยัง active ทั้งหมด 66 คน จะถูกรีเซ็ตรหัสผ่านเป็นรหัสใหม่
รีเซ็ตรหัสผ่านสำเร็จ: 66 บัญชี
แจ้งผู้ใช้ทุกคนให้เข้าสู่ระบบด้วยรหัสใหม่ แล้วไปเปลี่ยนรหัสเองในหน้าโปรไฟล์
```

## ข้อควรระวัง

- รหัสอย่าง `12345678` เป็นรหัสอ่อน ควรแจ้งผู้ใช้ให้เปลี่ยนทันทีหลังเข้าระบบครั้งแรก เพราะใครรู้รหัส default จะเข้าบัญชีอื่นได้จนกว่าจะเปลี่ยน
- ถ้ามีคน login อยู่ session เดิมยังใช้ได้จนหมดอายุ — ถ้าต้องการบังคับ logout ทุกคน ให้ล้างตาราง `user_sessions` เพิ่ม (เช่น ผ่าน `db:clean --only=user_sessions`)
- รันแล้วรีเซ็ตทุกบัญชี active ในครั้งเดียว ไม่มีการเลือกข้ามบัญชีบางคน (รวมถึงบัญชี admin) — ระวังใช้ในฐานข้อมูลจริง
- ถ้าต้องการให้ seed ครั้งหน้าได้รหัสเดียวกัน ตั้ง `SEED_DEFAULT_PASSWORD=12345678` ใน `server/.env` (seeder `011_users.ts` อ่านค่านี้อยู่แล้ว)
